# Обслуживание репозитория

## Гигиена

```bash
npm run check:hygiene
```

Команда формирует отчёт и ничего не удаляет автоматически. Она проверяет временные файлы, локальные `node_modules` и `dist`, legacy-конфигурации, папки с пробелами, `console.log` и `debugger`.

Основные правила:

- эксперименты хранятся в `brands/*` и `special/*`;
- новые папки называются в `kebab-case`;
- локальные зависимости и Vite-конфигурации не добавляются;
- временные workspace не редактируются вручную;
- несвязанные пользовательские артефакты не удаляются автоматически.

## Проверки

Минимальный общий набор:

```bash
npm run lint
npm run typecheck
npm test
npm run validate:configs
```

Полная проверка инфраструктуры:

```bash
npm run check:ci
```

## Каталог проектов

```bash
npm run update:catalog
```

Команда обновляет `docs/projects-catalog.md`. Этот файл генерируется автоматически и не редактируется вручную.

## Устаревшие utils

```bash
npm run check:deprecated-utils
```

Для контролируемой миграции старых импортов существует:

```bash
npm run migrate:utils
```

Миграцию следует запускать только в рамках отдельной согласованной задачи.
