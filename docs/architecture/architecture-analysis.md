# Анализ архитектуры

В репозитории используются разные уровни архитектурных карт. Они решают разные задачи и не заменяют друг друга.

| Задача                       | Команда                              | Результат                                          |
| ---------------------------- | ------------------------------------ | -------------------------------------------------- |
| Полный аудит исходного кода  | `npm run graph:audit`                | `graphify-out/graph.json`                          |
| Компактная карта репозитория | `npm run graph:project`              | `.architecture/project.json` и `.mmd`              |
| Подробная карта эксперимента | `npm run graph:experiment -- <путь>` | `.architecture/experiments/<проект>.json` и `.mmd` |

## Graphify

```bash
npm run graph:audit
```

Graphify выполняет полное AST-сканирование исходников. Команда использует установленный отдельно CLI `graphify`, принудительно обновляет устаревшие узлы и не отправляет документы или изображения в LLM.

`graphify-out` предназначен для редкого глубокого аудита: поиска центральных узлов, транзитивных связей и зон широкого влияния. Результат локальный и не коммитится.

## Компактная карта репозитория

```bash
npm run graph:project
```

Каждый эксперимент представлен одним узлом. Внутренние файлы экспериментов скрыты, но сохраняются его зависимости от общих модулей и npm-пакетов. Файлы инфраструктуры из `scripts`, `utils`, `templates` и `test` показываются отдельно.

## Карта эксперимента

```bash
npm run graph:experiment -- brands/sunmar/badge-family-hotels
```

Анализ начинается с entry-файла из `experiment.config.json` и рекурсивно проходит локальные импорты и зависимости от `@utils`. Можно передать короткое имя проекта, если оно уникально.

Анализатор читает JavaScript через AST. Для файлов с неподдерживаемым TypeScript- или JSX-синтаксисом используется ограниченный резервный разбор: он сохраняет импорты, но не анализирует внутреннюю структуру кода.

Папки `.architecture` и `graphify-out` локальные и не коммитятся. JSON предназначен для машинного анализа, Mermaid — для просмотра человеком.
