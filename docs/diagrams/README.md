# Граф-схемы проекта

Папка содержит архитектурные и процессные схемы репозитория в формате Mermaid.

## Схемы

- [`project-architecture.mmd`](./project-architecture.mmd) — верхнеуровневая структура репозитория и путь эксперимента от исходников до сборки.

## Правила

- Одна тема — одна схема.
- Исходный формат — `.mmd`; он является источником истины.
- При изменении архитектуры обновляй схему и этот индекс.
- Используй `kebab-case` для имён файлов.
