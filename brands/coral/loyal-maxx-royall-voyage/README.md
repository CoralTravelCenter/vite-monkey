# loyal-maxx-royall-voyage

Mindbox experiment based on Vite and vite-plugin-monkey.

## Settings

- Brand: `coral`
- Match: `https://www.coral.ru/*`
- Entry: `src/main.js`
- Styles: `src/styles/max_royale_banner.scss`

## Commands

```bash
npm run dev:experiment -- brands/coral/loyal-maxx-royall-voyage
npm run build:experiment -- brands/coral/loyal-maxx-royall-voyage
```

## Files

- `src/main.js` - entry point.
- `src/markup` - experiment markup.
- `src/styles/max_royale_banner.scss` - experiment styles.
- `experiment.config.json` - config for root-level `dev:experiment` and `build:experiment`.
