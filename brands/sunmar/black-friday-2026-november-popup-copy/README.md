# black-friday-2026-november-popup-copy

Mindbox experiment based on Vite and vite-plugin-monkey.

## Settings

- Brand: `sunmar`
- Match: `https://www.sunmar.ru/*`
- Entry: `src/main.js`
- Styles: `src/style.scss`

## Commands

```bash
npm run dev:experiment -- brands/sunmar/black-friday-2026-november-popup-copy
npm run build:experiment -- brands/sunmar/black-friday-2026-november-popup-copy
```

## Files

- `src/main.js` - entry point.
- `src/markup.html` - experiment markup.
- `src/style.scss` - experiment styles.
- `experiment.config.json` - config for root-level `dev:experiment` and `build:experiment`.
