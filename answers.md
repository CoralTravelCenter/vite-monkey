# Ответы

## sunmar-ny-2027-gnb-mobile

Проект переведен на мобильное меню `HeaderMobileMenuList_headerMobileMenuList__`.

- Новый пункт вставляется в начало DOM, после чего CSS-порядок переносит его на предпоследнюю позицию.
- Обычные пункты остаются с исходным `order: auto`.
- Новогодний пункт получает `order: 1`.
- Пункт «Еще», найденный по вложенной кнопке раскрытия, получает `order: 2` и остается последним.
- Проверка от повторной вставки теперь использует корректный мобильный класс `.sunmar-ny-2027-gnb-mobile`.
- Исправлена поздняя загрузка меню: `MutationObserver` ожидает появление мобильного контейнера после открытия бургер-меню и вставляет элемент при его создании.
- Контейнер пункта получил штатный `padding: 8px`, как у `HeaderMobileMenuListItem`; у самой ссылки внутренний отступ обнулён. Фон остаётся прозрачным.
- Для точного совпадения виджет теперь копирует CSS-классы штатных `HeaderMobileMenuListItem`, `title` и `titleLink`. Ручные размеры, шрифт, фон и отступы удалены; они полностью берутся из актуальных стилей сайта.
- По базе `coral-travel-useful-features` зафиксированы штатные типографические токены Sunmar: `Museo_Sans`, `16px/24px`, `font-weight: 600`, `letter-spacing: 0`, цвет `#000`. Они применяются также для `hover`, `focus`, `active` и `visited`.
